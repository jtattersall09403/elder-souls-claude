## 2. The defect the builder could not root-cause — `bed_gain_db` is not a scalar. **Found.**

**Cause.** `game/src/audio/synth.js` `attachMod()` (lines 139–143), for `mod.target === 'gain'`:

```js
const base = targets.gain.gain.value;              // == dbToGain(synth.gain_db). Nothing else yet.
targets.gain.gain.value = base * (1 - mod.depth * 0.5);
amt.gain.value = base * mod.depth * 0.5;           // the LFO SWING, an absolute number
amt.connect(targets.gain.gain);                    // AudioParam connections are ADDITIVE
```

`game/src/audio/ambience.js` `buildBedContinuous()` (line 374) then applies the level and the trim:

```js
const target = h.gain.gain.value * dbToGain(levelDb || 0) * trim;   // scales the STATIC term ONLY
```

So the layer's instantaneous gain is

```
gain(t) = base·(1 − d/2)·L·trim   +   sin(2πft)·base·(d/2)
          └── follows the trim ──┘       └── does not ──┘
```

`bed_gain_db` is a scalar on one term and a no-op on the other. **`level_db` has the identical bug**, on
the same line.

**Proof, by rendering the same bed with and without that one node** (`tools/analysis/critic-w1-22-probe.mjs`,
valus-ridge, 20 s @ 16 kHz, trim −13.24 → −15.30, i.e. −2.06 dB, at `78aebc7`):

| variant | Δ LUFS-I | Δ peak (dB) | Δ band centroid | Δ power centroid |
|---|---|---|---|---|
| **as shipped** | **−1.421** | **−0.918** | **−132.7 Hz** (2057.8 → 1925.1) | −5.1 Hz |
| **L1 gain-mod deleted** | **−2.060** | **−2.060** | **0.0 Hz** (1917.6 → 1917.6) | **0.0 Hz** |

The "as shipped" row reproduces the builder's SUCCESSOR-8 numbers **to the decimal** (−1.42, −0.92,
2057.8 → 1925.1) with independently written DSP. Delete the gain LFO and the trim becomes exactly scalar
and the centroid becomes exactly invariant. That is the mechanism, and nothing else in the file predicts a
*falling* centroid: valus-ridge's gain-modulated layer is the **low** one (a 146–262 Hz drone) and its
un-modulated layer is the **high** one (a 2400 Hz highpass), so attenuating the trim leaves relatively more
low-frequency energy behind.

**It is worse than a calibration nuisance, and it is on the live path.** Straight from the running data:

```
l1 synth gain_db −2, level_db 0, bed_gain_db −15.30, mod {gain, 0.11 Hz, depth 0.42}
static term      0.1078
LFO swing term   0.16681
swing / static   1.547          gain_goes_negative_at_trough: TRUE
```

A declared **42 %** tremolo is running at an effective **155 %** and the gain parameter goes **negative**
at every trough, so Valus Ridge's rock-flute chord **phase-inverts** once every nine seconds. `synth.js`'s
own comment says the bias exists "*so that a `depth: 1.0` gain modulation reaches silence at the trough
rather than clipping at the peak*" — the later multiplication defeats that intent, and the larger the trim
the more it defeats it. `buildBedContinuous()` is called by **both** `renderBedOffline()` **and**
`AmbienceDriver._swapLive()`, so this is what a player hears, not a measurement artefact. Ranking the beds
by |trim| predicts which drift: valus-ridge −15.30 (worst — and it is the one that drifted), stone-forest
−11.24 (second — also a gain-modulated L1).

**Remedy (three lines).** Apply `level_db` and `trim` **before** `attachMod` — or scale `amt.gain.value` by
the same factor. Then `--calibrate`'s one-shot `target − measured` correction is correct and needs no
iterating, and the builder's "iterate to convergence" workaround becomes unnecessary.

## 6. Interiors (R4) — **the item does not permit what was shipped**, and the framing should change

The handoff says interior beds are "deliberately absent". Checked against the items:

- **RI-AUD03 R4** reads: "**Interiors get their own bed**, not the exterior bed at −12 dB." It *forbids* the
  low-passed exterior — which the builder correctly avoided — and it *mandates* a bed. **Silence is a third
  option R4 does not sanction.**
- **RI-WLD08 §6**, the other item judging `audio.ambience.region`, is explicit: **"≥13 (one per region) + ≥8
  settlement beds + ≥4 interior beds"**, and "≥25 positional ambient emitters per km²". The build has 13 + 0 + 0,
  and 4 emitters in the whole province.

And the suppression is broader than "cellars". Measured in the running world (`E_suppression`, `78aebc7`),
**all six** named cells suppress — including **`helstrom-market`** and **`stormhold-street`**, which are
settlements. `interiors_in_data: 115`. So today, walking into any town in Black Marsh drops the world to
**absolute silence**.

So the honest statement is not "R4 permits this" but: **R4 is not met; the failure R4 names is avoided; 115
interiors and every settlement are silent and it is declared.** That is a good absence — `getAmbienceState().suppressed`
names the cell and `getUnimplemented` carries the entry — but it is debt, not a design statement.
(One instrument smell: while suppressed, `getAmbienceState()` still reports the exterior bed's four layer
ids and `voices_active: 3`. Only `suppressed` tells you it is silent.)

I did **not** call this AR-2 leakage. The AR-2 clause is "near-total silence outside boss arenas so the
world reads as a mausoleum", and the thirteen exteriors are emphatically not silent. S26 forbids diluting
the AR checks to cover ordinary defects, and this is an ordinary defect.

## 9. The single biggest gap

**`GAP-W1-audio-emitter-consumption` — the positional emitters are silent on every path the game can reach.**

- **What.** `AmbienceDriver.step()` computes `emitterPlacement()` for all four R7 emitters every frame,
  reports them `audible: true` with a gain and a pan, and counts them against the voice budget — and never
  schedules a grain. The only code that sounds an emitter is `renderBedOffline()`'s `opts.listener` branch,
  and nothing in the tree passes `listener`. Measured: `+40 dB` on `bell_buoy.level_db` leaves the live
  render **bit-identical** (0.4197283983230591 both runs) while the same perturbation on L1 clips the output.
- **Why it matters.** RI-AUD03 R7 makes the emitters navigational — "*a player who has learned the bell can
  locate themselves in fog*" — and that is the ambience contribution to **S8 (no map markers)**. A player in
  fog on Marauder's Coast today hears nothing and has nothing to steer by.
- **Remedy.** In `AmbienceDriver.step()`, give the emitters their own `LayerClock` keyed on `period_s` and
  call `buildGrain(this.ctx, {...e, level_db: e.level_db + bedTrimDb(bed)}, this.live.bus, this.rng, when, pl.pan, pl.gain)`
  when `this.ctx && this.live && pl.audible`; `_emit()` an `ambience_emitter` row carrying `pan`, `gain` and
  `distance_m` so B6's stated instrument (`audioLog.pan`) exists; pass `listener` from
  `ambienceCapture()` so emitters appear in a measured clip; and bound `period_s` in `ambience-census.mjs`
  (`kiln` has none at all, `bell_buoy` is 13 s).
- **Acceptance.** Perturbing any emitter's `level_db` by +20 dB moves the live-path rendered peak by >1 dB;
  `ambienceLog()` contains emitter rows with monotonic `pan` along the 200 m transect (B6 as written);
  every emitter declares a `period_s` ≥ 45 s.

**Second-biggest, and cheap:** fix `attachMod`'s unscaled swing (§2). Three lines, and it removes a
155 %-depth phase-inverting tremolo from a shipped bed.
