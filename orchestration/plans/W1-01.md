### S51 (2026-08-14) — two of this plan's three blind comparisons are built from the tables the build was built to satisfy

`corpus/00-doctrine/ARBITRATION.md` **S51** landed while this round was in progress and it binds
above every item's stated comparison method. Its test, so a builder can apply it without an arbiter:
**the disconnected-script test — could a short script that has read the item's tables, and has never
run the game, reproduce the judge's answer?** If yes, the pack measures conformance to a table both
arms encode, the human is decoration, and it scores `0` with `blind: void` and the reason — never
"pass". S51's named blast radius includes **`RI-CAM02` (§C)** and **`RI-AI05` (§B)**, which are
steps 11 and 9 of this plan.

The four admissible counterpart classes: **(A)** an authentic external artefact; **(B)** a
runtime-generated reference from an independent implementation actually run; **(C)** an authored
exemplar of the same kind, written independently of the acceptance thresholds; **(D)** a
within-build ablation contrast, both arms ours, differing by exactly the mechanism under test. A
class-D contrast **may never be recorded as a reference pair**; where no admissible counterpart
exists the honest record is `blind_status: not_possible` **with the reason**, and the class-D
contrast runs beside it as a named substitute instrument.
