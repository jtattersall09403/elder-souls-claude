## Build order and acceptance evidence

1. **Freeze and census.** Stamp HEAD, run the canonical data/boot/corpus gates, inventory every path and
   every required harness field. Produce a machine-readable requirement matrix keyed by item/method;
   missing methods are red. Confirm actual runtime combat path by perturbation before changing it.
2. **Close the geometric root defect first.** Repair the weapon/body seam without a proximity damage
   check. Run 0.05 m reach sweeps, per-frame volumes and weapon-only/body-only/both/neither 2x2. A passing
   build has contiguous bands, weapon-delivered ordinary damage, a lower-priced motion-dependent body
   contact, and a non-inert separation/substep model. Preserve root-dz=0 and stationary-adjacent guards.
3. **Close time/economy/exchange defects.** Exact guard/stagger/parry/heal/jump/stamina behavior, amended
   combo diversity, f_vis/divergence and the full exemplar. Never tune only the exemplar: fixed scripts,
   seeds and fixtures are preregistered before adjustment.
4. **Run every governing item, then aggregation.** The acceptance predicate is conjunctive: each item's
   native score reaches its own bar, W1-09 aggregate reaches >=7.0/10, and **zero governing hard fail or
   automatic fail fires**. A cross-piece dependency may make a row `not_run`; it may not turn it green.
5. **Controls.** For each changed mechanism produce baseline/fix/delete-fix plus targeted null. Prove code
   execution with a trace counter. Delete-fix must restore the baseline defect; if deleting one of two
   guards does nothing, report the 2x2 rather than calling it inert. Browser/world is authoritative over
   node; `cmb-reach --verify` must compare both and fail on a deliberately induced steering divergence.
6. **Critic pack.** Commit-stamped raw JSON/JSONL, seeds, fixtures, item versions, digests, commands and
   summaries; actual images/video/audio where an item asks human judgement; blind mapping outside the
   pack; independent critic-authored recomputation; all null/red/delete arms; boot/data/corpus and full
   aggregation outputs. The builder must disclose any plan defect immediately.
