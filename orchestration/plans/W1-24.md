## Acceptance plan

1. **Instrument integrity.** Run both `--self-test` suites. Required: cc-scan 14 cases, 9 deliberate
   defects, 0 inert; visual-reading 11 readings, 7 defects, 0 inert. Disable each check one at a time
   and require exactly its unique case to escape. Empty samples and all-void corpora fail.
2. **Corpus scan.** Run cc-scan across the complete verdict population. Each visual claim has a
   declaration before first capture, singular legal judgement side, item-parsed properties,
   matching permitted/forbidden references, resolvable capture with exact SHA-256, no fused sides,
   and no opposite-side judgement in prose. Lexical tripwire never alone changes verdict. Publish
   counts by CLEAN/TRIPWIRE/VOID/ABSENT/NOT_APPLICABLE and every filename.
3. **Ruling artifact.** File the RI-VIS01 effective-date/retroactivity seam through existing
   ARBITRATION/amendment machinery. Acceptance is an explicit reversible ruling naming which
   historical population must be remediated. Until then, report both literal and prospective counts.
4. **Live audit.** Reuse `w1-24-audit.mjs`, one browser, four named claims. For each publish Q1–Q5,
   subject×clock values, all sabotage arms, degenerate support count, concurrent failures, capture
   hash and commit. Expected discrimination: constant canvas goes `PASSES_ON_DEGENERATE`; eight-town
   claim with buildings removed goes `NULL_CONTROL_FAILED`; valid scene-graph interior claim stays
   OK; FD6 empty-edge case remains `DEGENERATE_NOT_GRADEABLE` until a known-bad nonempty capture exists.
5. **RI-CAM07.** Amend `tools/harness/viewpoints.json` with canonical
   `player_back_closeup`/`player_front_closeup` only if absent at HEAD, then capture both at required
   native frame, camera mode and ≥45% character-height framing. Run all M1–M4 predicates and every
   hard fail in RI-CAM07. Back/front measurements use identical crop, pose, light and animation
   frame. Delete/hide the player mesh: character-support predicate must fail while world render
   remains live. Swap front/back or freeze animation: the relevant arm must change.
6. **B1 seam.** Do not build around the contradiction. Proposed amendment must specify a native
   window size that fits the crop, a separately calibrated band, fixtures and reference population;
   then `tools/metrics/lib/vis03.mjs` must implement that named path and reject resampling. Before
   amendment, B1 is unmeasurable/0 exactly as the item says.
7. **References and blind judgement.** Use only RI-VIS09-permitted references for the declared side.
   Build the RI-VIS06 pack with actual images, equal presentation, coin-flipped ordering, recorded
   seed, quarantine and reveal. A fresh judge answers the native quality question; the builder never
   judges. Tells audit covers filename, order, dimensions, compression, border and metadata.
8. **UI style.** Run all applicable RI-UIX06 native checks on shipped HUD/menu surfaces at required
   viewports, with forbidden-reference exclusion and null styles. Protocol compliance cannot stand
   in for meeting its actual visual/style thresholds.

inadmissible surface, subject/clock blindness, inert sabotage, passing gradeable degenerate, empty
support reported green, resampled M5 called native, blind tell/reveal leak, self-judgement, or any
item-native hard fail. Outputs: `reports/w1-24/` (new stamped run files, without rewriting historical
ones), canonical viewpoint amendment, corpus amendment/ruling, and quarantined blind artifacts.
